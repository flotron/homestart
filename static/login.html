First-time setup

Create the owner account

This single account will have full access to HomeStart, including files, Samba, Docker and server settings.

Find “Setup code” in the HomeStart service journal:
sudo journalctl -u homestart.service -n 60 --no-pager
This works with both default and custom installation directories.
